# 408-code-by-book
1.正在收录王道大题25版的代码解法，目的在于方便大家调试题目代码，不要重复造轮子，每个代码文件对应其题号；我尽量将main函数和测试函数都给了出来，方便大家直接下拉到本地电脑研究调试，另外王道每年的书大题变化几乎可以忽略不计，如有变化，欢迎补充，也欢迎commit&push出更好的解法；

2.任意语言，但是文件的名字格式请设置为：王道[版本年号]数据结构[章节号][题目类型][题号]；
